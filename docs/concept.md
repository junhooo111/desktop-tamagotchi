# 컨셉

## 한 줄 요약

AI로 화면을 만들다 보면 놓치기 쉬운 FE 기본기를, 바탕화면을 돌아다니는 픽셀 동물이 짚어 주고 함께 키우며 배우는 데스크톱 펫.

## 목표

- AI가 만들어 준 화면에서 빠진 디테일을 **내가 직접 이해하고 확인**하게 만든다.
- 확인하고 배운 만큼 펫이 성장해서, 학습이 눈에 보이는 보상이 된다.

## 핵심 루프

1. 펫이 바탕화면을 돌아다닌다.
2. 개발 중인 `localhost` 페이지에서 놓친 부분을 발견하면 해당 위치로 가서 알린다.
3. 말풍선 카드로 "무엇이 문제인지 + 왜 문제인지 + 기본 지식"을 보여 준다.
4. 사용자가 내용을 확인하면 경험치를 얻고, 펫이 성장한다.
5. 고친 뒤 다시 검사해서 사라지면 보너스 경험치를 준다.

## 검사 방식

- 개발 중인 `localhost` 페이지에만 연결한다(크롬 개발자 도구 프로토콜).
- 화면 전체를 캡처해서 외부 AI로 보내는 방식은 쓰지 않는다. 회사 PC에서 쓰기 때문이다.
- 후보 항목: 접근성(대체 텍스트, 폼 라벨, 명도 대비, 제목 순서), 레이아웃(가로 스크롤, 잘린 텍스트, 너무 작은 터치 영역), 마크업(`lang`, `title`, viewport 메타), 하드코딩된 px 간격.
- 화면 밖 의미(로딩·빈 화면·오류 상태가 있는지 등)는 자동으로 알 수 없다. 이런 건 체크리스트 카드로 따로 안내한다.

## 성장·수집

- 경험치로 레벨이 오르고 단계가 바뀐다(알 → 새끼 → 성체).
- 학습 보상으로 재화를 모아 뽑기로 새 펫을 얻는다.
- 펫 종류마다 희귀도가 있다.
- 처음엔 종류를 2~3개로 시작하고 점차 늘린다(픽셀아트 제작량이 가장 큰 변수).

## 영감

- gitanimals: GitHub 프로필에 펫을 등록해 키우는 오픈소스. 수집과 성장이 재미있어서 참고한다.

## 단계

1. 기본 틀: 투명 창, 픽셀 동물, 돌아다니기, 상태 저장, 경험치·성장
2. 검사: localhost 페이지 검사 + 학습 카드 + 확인 시 경험치
3. 지식 알림: FE 지식 피드를 말풍선으로
4. 수집: 펫 종류, 희귀도, 뽑기
5. (선택) 화면 캡처 AI 검사. 개인 PC에서만, 사용자가 켰을 때만
