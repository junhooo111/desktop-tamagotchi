## 2026-11-24 — 1단계 기본 틀

- 기술 스택 확정: Electron + TypeScript, 테스트는 Vitest.
- 구현: 투명·항상 위 창, 6종 픽셀 스프라이트(16x16 대칭, 왼쪽 절반만 정의), 배회, 끌기, 쓰다듬기·밥·놀이, 알 → 새끼 → 성체, 꺼 둔 시간 반영, JSON 저장, 트레이.
- 규칙(성장·배회·저장)은 화면과 분리한 순수 모듈로 두고 테스트 49건으로 고정했다.
- 검증: 빌드·단위 테스트·스모크(창을 띄워 렌더러 오류 없음 확인) 통과. 실제 화면에서 걷기·끌기·클릭 통과·메뉴·트레이를 눈으로 확인하는 건 아직이다.
- 알려진 한계: 그림은 임시 도트(정면 대칭, 걷는 동작은 튀는 효과뿐). 알 → 새끼 → 성체는 같은 그림의 크기만 달라진다.
- 다음: 직접 실행해서 느낌을 보고 조정한 뒤 2단계(localhost 페이지 검사 + 학습 카드).

## 2026-11-24 — 옆모습 전신·다양한 동작으로 개편

- 요청: 마우스 커서만 한 크기로 줄이고, 정면 대칭 대신 옆모습 전신에 픽셀 움직임을 넣는다. 졸기·자기, 뛰기, 걷기, 벽 타기, 미끄러지기, 마우스에 매달리기(10초 방치), 혼자 놀기.
- 그림 방식 변경: 문자열 격자를 손으로 찍는 대신 타원·사각형을 겹치고 윤곽선을 자동으로 두르는 코드(`pixel.ts`)로 그린다. 다리 위치만 바꿔 걷기·뛰기 프레임을 만들고, 벽 타기는 같은 그림을 뒤집고 90도 돌려서 쓴다.
- 크기: 한 칸 2배(알·새끼 32px), 3배(성체 48px). `layout.ts` 의 `STAGE_SCALE` 만 고치면 된다.
- 창은 펫보다 크게(160x120) 두어 말풍선·점프 자리를 확보하고, 창 위치를 펫 기준으로 계산해서 펫이 화면 가장자리까지 닿는다.
- 행동은 `behavior.ts` 상태 머신으로 분리: idle → 걷기/뛰기/졸기/놀기/벽 타기 중 하나. 졸다가 70%는 잠든다. 벽 타기는 가장자리로 걸어가 오르고, 초당 12% 확률로 미끄러진다.
- 매달리기: 마우스를 10초 가만히 두면 달려와 매달리고, 마우스가 6px 넘게 움직이면 떨어진다. 매달린 동안은 펫이 입력을 받지 않아 클릭이 그대로 통과한다. 알·자는 펫·벽 타는 펫은 오지 않는다.
- 집어서 놓으면 중력으로 바닥까지 떨어진다. 자는 펫은 클릭하면 깬다.
- 메뉴에 `동작 보기 (테스트용)` 추가(잠자기·달리기·벽 타기·혼자 놀기).
- 검증: 타입 검사, 단위 테스트 117건, 스모크 통과. 그림은 이미지로 렌더해 확인했다. 실제 화면 동작(벽 타기 위치, 매달리기, 창이 화면 밖으로 걸칠 때의 모습)은 직접 실행해서 확인해야 한다.
- 알려진 한계: 화면 위쪽 가장자리에서는 말풍선이 화면 밖으로 잘릴 수 있다. 천장 걷기는 없다. 그림은 여전히 임시 도트다.
